# FarmDirect / TheFarmers

A clean-room recreation inspired by the FarmDirect marketplace website, rebuilt with a cleaner React + Vite frontend and a modern Node.js + Express backend.

## Structure

- `client/` — React application with Tailwind styling and route-based navigation
- `server/` — Express API server with MySQL integration and JWT authentication
- `database/` — SQL schema for marketplace data models
- `docs/` — API docs and deployment guidance

## Quick start

1. Install frontend dependencies:
   ```bash
   cd thefarmers/client
   npm install
   ```
2. Install backend dependencies:
   ```bash
   cd ../server
   npm install
   ```
3. Create `.env` files from the examples and run frontend/backend.
